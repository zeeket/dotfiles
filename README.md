# dotfiles

Configuration files: bash, zsh, Vim, Debian, etc.

The zsh dotfiles (`.zshrc`, `.zsh_aliases`, `.zprofile`, `.zlogout`) are oh-my-zsh
equivalents of the corresponding bash dotfiles (`.bashrc`, `.bash_aliases`,
`.bash_profile`, `.bash_logout`). `.zshrc` expects oh-my-zsh to be installed at
`~/.oh-my-zsh`.
